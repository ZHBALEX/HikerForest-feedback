# HikerForest — player feedback / 玩家反馈

[Play the game / 在线游玩](https://zhbalex.github.io/HikerForest/)

This public repository is for feedback, ideas, and bug reports only. The game source is maintained separately.

- Enjoyed the game? Tell us what worked, or add a reaction to a relevant issue.
- Found a problem? Include the journey, round, difficulty, and steps to reproduce it. A screenshot helps.
- Have an idea? Small improvements and honest first impressions are welcome.

Playing requires no login. Posting here requires a GitHub account. Issues and comments are public; please do not include private information.

这个公开仓库只用于玩家反馈、建议和问题报告，不包含游戏源码。游玩无需登录，留言需要 GitHub 账号。欢迎用中文或英文告诉我们哪里好玩、哪里不清楚，或提交截图和复现步骤。留言公开可见，请勿包含隐私信息。
